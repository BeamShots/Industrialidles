# Tideforge
Extract the ZIP. Upload the individual files together to the top level of a GitHub repository. In Settings → Pages select Deploy from a branch, main, / (root), and Save. Open the published Pages URL in Android Chrome while online. Use the browser menu → Add to home screen → Install. Keep the same site address for your local save. Factory time runs while playing.
 
First line: find the blue deposit two tiles left of center. Place a drill on it, then a belt, furnace, and depot on the next three tiles to its right. Leave the output arrows facing right. Ingots pay for land and voyages in Chart. Drag the sea to pan; Center brings you home.
