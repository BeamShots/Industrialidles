# Generated game art
Generated with the built-in image generation tool for this game and incorporated as local WebP assets. No external art requests are made at runtime.

assets/atlas.webp
A transparent, aligned 4×4 sprite atlas. The generation prompt requested richly shaded top-down pixel art with one separate object per cell.
Rows, in order:
1. Pine, silver rock, iron deposit, copper deposit.
2. Crystal deposit, mining drill, orange furnace, cargo depot.
3. Sawmill, quarry, emerald gel furnace, wire mill.
4. Steel forge, crystal extractor, coin mint, green slime.
The sheet is sampled by cell for the canvas and by CSS background position for the build catalogue and enemies.

assets/frame.webp
The prompt requested a single empty nautical RPG frame with dark walnut edges, brass corners, a jade inset and dark teal leather center, without text. It is applied as a nine-slice border image so functional game text and buttons remain readable at different screen sizes.

assets/marsh.webp
The prompt requested a wide magical mangrove marsh at twilight with mossy arches, slime pools, fireflies and an uncluttered water clearing for enemies. Used behind expeditions and the exploration introduction.

The existing AI-generated furnace app icon remains in use.
